# African Indigenous Seeds

**Preserving our heritage. Empowering farmers. Growing Africa.**

## 1. About the Project

African Indigenous Seeds is a community-driven digital marketplace designed to connect indigenous seed savers, farmers and seed producers with people seeking indigenous planting materials across Africa.

The platform aims to conserve agricultural biodiversity, improve access to affordable indigenous seeds and strengthen community livelihoods.

## 2. Vision

A thriving Africa where indigenous seeds are preserved, shared and accessible to present and future generations.

## 3. Mission

To promote indigenous seed conservation, support seed-saving communities and create accessible markets for indigenous seeds across Africa.

## 4. Main Features

- Free membership registration.
- Manual membership approval by administrators.
- Marketplace for indigenous seeds.
- Seed listings with photographs, prices and quantities.
- Search and filter by seed category and location.
- Buyer order requests.
- Seller order management.
- Buyer order tracking.
- Administrator dashboard.
- Member notifications.

## 5. Membership

Only approved members of African Indigenous Seeds can publish seed listings.

Membership is free.

Membership categories include:
- Farmer
- Seed saver
- Seed producer

## 6. Seed Categories

- Indigenous vegetables
- Indigenous cereals
- Indigenous fruits
- Indigenous trees
